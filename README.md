## 🎨 Customization Guide

### 1. Love Letter (Page 4)

Edit the text in `index.html`:

```html
<p id="typing">
Your love letter here...
</p>
```

### 2. Photo Gallery (Page 5)

Place 6 images in the `images/` folder:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

### 3. 12 Reasons (Page 6)

Edit each reason card in `index.html`:

```html
<div class="reason-card">
  <h3>🤍 Reason #1</h3>
  <p>Your reason here</p>
</div>
```

### 4. Timeline (Page 7)

Edit dates and memories in `index.html`:

```html
<div class="timeline-item">
  <span class="date">DD Month YYYY</span>
  <h3>Memory Title</h3>
  <p>Memory description</p>
</div>
```

### 5. Birthday Wishes (Page 9)

Edit in `index.html`:

```html
<p id="wishes-text">
Your wishes here...
</p>
```

### 6. Background Music

Place your audio file at `music/song.mp3`

## 🚀 Deployment

### GitHub Pages

1. Push to GitHub
2. Go to Settings → Pages
3. Select `main` branch
4. Your site is live!

### Local

Simply open `index.html` in your browser.
